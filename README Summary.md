## Testing Techniques Applied

**Boundary Value Analysis (BVA)**
- Tested minimum, maximum, and boundary values
- Example: Password length (7, 8, 20, 21 characters)

**Equivalence Class Partitioning (ECP)**
- Divided inputs into valid/invalid classes
- Example: Valid email, invalid email, special characters

**Positive & Negative Testing**
- Valid inputs: verified system works correctly
- Invalid inputs: verified graceful error handling
